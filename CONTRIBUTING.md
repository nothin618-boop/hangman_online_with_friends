# Contributing to Whisper Game

Thank you for your interest in contributing to Whisper Game!

## How to Contribute

1. **Fork the Repository**: Create your own copy of the repository.
2. **Create a Branch**: `git checkout -b feature/your-feature-name`
3. **Make Changes**: Keep changes focused and test thoroughly.
4. **Commit**: Write clear, descriptive commit messages.
5. **Open a Pull Request**: Submit your PR with a description of the changes and motivation.

## Development Guidelines

- Ensure your code passes TypeScript checks: `pnpm run build`
- Follow existing code style and formatting conventions.
- Test your modifications locally across both desktop and mobile viewports.
